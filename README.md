# 🚀 Manim Animation Learning Journey

A collection of **practice code, animation scenes, and experiments** documenting my journey building educational animations with Manim.

## 📖 About This Repository

This is **not a single project** - it's a **personal animation repository** where I practice and explore:

- 🎬 Manim scene creation
- ✨ Motion graphics and visual storytelling

Each file represents an animation scene, practice implementation, or reusable helper as I continue improving my animation workflow.
